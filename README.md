# 海老フライ王国AR ～日野町大冒険～

滋賀県日野町を巡りながら、GPSとARを使ってキャラクターを集めるスマートフォン向けブラウザゲームです。スポット訪問、キャラクター収集、Quest、Achievement、Storyを進め、海老フライ王国の物語とコンプリートを楽しめます。

## 遊び方

1. HTTPSで公開されたゲームページをスマートフォンのブラウザで開きます。
2. 「冒険をはじめる」を押し、ブラウザから求められた位置情報の利用を許可します。
3. 安全な場所に立ち止まり、日野町の対象スポットを巡ります。
4. スポットでキャラクターを発見したらAR画面を開きます。
5. キャラクターを捕まえて図鑑へ登録し、QuestやAchievementを進めます。
6. Storyを最後まで進め、ゲームクリアを目指します。

歩きながら画面を操作しないでください。私有地、立入禁止区域、車道などへ入らず、施設や地域のルールに従って遊んでください。

## GPS

スポットの判定には端末の位置情報を使用します。位置情報を許可し、屋外など測位しやすい場所で利用してください。位置情報が拒否された場合や精度が不足する場合、スポット訪問やキャラクター取得を進められないことがあります。

## カメラ

AR表示には端末のカメラを使用します。カメラ機能はHTTPS環境またはlocalhostで利用できます。カメラを利用できない場合や許可しなかった場合は、カメラを使わない簡易ARモードへ切り替わります。

## 保存

ゲームの進行状況はブラウザの`localStorage`へ保存されます。ブラウザデータの削除、プライベートブラウズ、端末やブラウザの変更によって保存データを利用できなくなる場合があります。

## 動作環境

- スマートフォンまたはタブレット
- ES2022に対応するモダンブラウザ
- iPhone／iPad: Safariの現行版
- Android: Google Chromeの現行版
- JavaScript、`localStorage`、位置情報の利用が可能な環境
- カメラARを使う場合はカメラ機能とHTTPS接続

端末、OS、ブラウザ、権限設定、通信状況、GPS精度によって動作が異なる場合があります。デスクトップブラウザでも画面は表示できますが、GPS・カメラを使った実際のゲームプレイはスマートフォンを推奨します。

## 公開方法

本プロジェクトは静的なHTML、CSS、JavaScriptで構成されています。GitHub PagesなどのHTTPS対応静的ホスティングへ、そのまま配置できます。
